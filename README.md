
📊 Seller Data Analysis Project
📌 Overview

This project focuses on analyzing seller data to extract meaningful insights that can help improve business decisions. The analysis includes data cleaning, exploratory data analysis (EDA), and visualization to understand patterns in sales, performance, and trends.

🎯 Objectives
Clean and preprocess raw seller data
Perform exploratory data analysis (EDA)
Identify trends and patterns in sales
Visualize key metrics using charts and dashboards
Generate actionable insights
🛠️ Tools & Technologies Used
Python (Pandas, NumPy)
SQL (for querying structured data)
Excel (data cleaning & preprocessing)
Power BI (dashboard & visualization)
📂 Dataset

The dataset contains seller-related information such as:

Seller ID
Product details
Sales amount
Quantity sold
Date of transaction
Region / Location
🔍 Project Workflow
1. Data Cleaning
Removed null values
Handled duplicates
Standardized column names
2. Exploratory Data Analysis (EDA)
Sales distribution analysis
Top-performing sellers
Monthly and yearly trends
3. Data Visualization
Bar charts for top sellers
Line charts for sales trends
Pie charts for category distribution
4. Dashboard Creation
Built an interactive dashboard in Power BI
Key KPIs:
Total Sales
Total Orders
Top Sellers
Region-wise Performance
📈 Key Insights
Identified top-performing sellers contributing most revenue
Found seasonal trends in sales
Highlighted underperforming regions needing improvement
